# 🛡️ Alibaba OpenCodeReview (OCR) অটোমেশন গাইড

এই প্রজেক্টে এবং আপনার ভবিষ্যৎ সকল প্রজেক্টে **Alibaba OpenCodeReview (OCR)** স্বয়ংক্রিয়ভাবে চালানোর সম্পূর্ণ কনফিগারেশন সেটআপ করা হয়েছে। আপনার কোনো ম্যানুয়াল কাজ করতে হবে না; প্রতিবার `npm run deploy` দিলে বা GitHub-এ পুশ করলে এটি ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে কোড স্ক্যান করে ত্রুটি ও সিকিউরিটি বাগ ধরবে।

---

## ১. কীভাবে স্বয়ংক্রিয়ভাবে কাজ করে?

### ক) লোকাল প্রি-ডিপ্লয় চেক (`npm run deploy`):
- যখনই `npm run deploy` দেওয়া হয়, কোড কমিট ও পুশ হওয়ার আগেই `scripts/ocr-check.js` এক্সিকিউট হয়।
- এটি পরিবর্তিত ফাইলগুলোর মধ্যে আলিবাবার নিয়মাবলি (XSS, Injection, Dangerous DOM methods, Concurrency, Strict Equality, NPE) চেক করে।
- কোনো বড় সিকিউরিটি রিস্ক বা কোড ডিফেক্ট থাকলে এটি আগেই পুশ ব্লক করে সতর্কবার্তা দেবে।

### খ) GitHub Actions অটোমেশন (`.github/workflows/open-code-review.yml`):
- প্রতিবার GitHub-এ `push` বা `pull_request` আসার সাথে সাথে GitHub Actions রানার সক্রিয় হয়।
- কোনো অতিরিক্ত API Key বা কনফিগারেশন ছাড়াই এটি আলিবাবার ডিটারমিনিস্টিক রুলস ইঞ্জিন চালিয়ে কোড স্ক্যান করে।
- স্ক্যান রিপোর্ট সরাসরি GitHub Action-এর **Summary Tab**-এ সুন্দর টেবিল আকারে দেখা যায়।

## ২. অন্য যেকোনো প্রজেক্টে এই ফিচার চালু করার নিয়ম (১ মিনিটে সেটআপ)

আপনার পরবর্তী যেকোনো প্রজেক্টে এটি যুক্ত করতে মাত্র ২টি ফাইল কপি করে নিলেই হবে:

1. **`scripts/ocr-check.js`** ফাইলটি আপনার নতুন প্রজেক্টের `scripts/` ফোল্ডারে পেস্ট করুন।
2. **`.github/workflows/open-code-review.yml`** ফাইলটি নতুন প্রজেক্টের `.github/workflows/` ফোল্ডারে পেস্ট করুন।
3. আপনার নতুন প্রজেক্টের `package.json`-এ নিচের লাইন দুটি যোগ করুন:
   ```json
   "scripts": {
     "ocr:check": "node scripts/ocr-check.js",
     "deploy": "node scripts/ocr-check.js && git add . && git commit -m \"chore: auto deploy update\" && git push origin HEAD:main"
   }
   ```

ব্যাস! আপনার নতুন প্রজেক্টেও প্রতিটি পুশ ও অর্ডারের সাথে আলিবাবার এআই কোড রিভিউয়ার স্বয়ংক্রিয়ভাবে কাজ করা শুরু করবে।

---

## ৩. (ঐচ্ছিক) পুল রিকোয়েস্টে লাইভ এআই কমেন্টিং চালু করা

আপনি যদি চান আলিবাবার AI সরাসরি GitHub PR-এর প্রতিটি লাইনে নিজে কমেন্ট করুক:
1. GitHub রিপোজিটরির **Settings** > **Secrets and variables** > **Actions** এ যান।
2. **`OCR_LLM_KEY`** বা **`OPENAI_API_KEY`** নামে একটি Secret তৈরি করে আপনার API Key দিন।
3. API Key দিলে এটি স্বয়ংক্রিয়ভাবে AI মডেল (যেমন GPT-4o-mini / DeepSeek) ব্যবহার করে PR-এ বিস্তারিত রিভিউ পোস্ট করবে। না দিলেও কোনো সমস্যা নেই—ডিটারমিনিস্টিক রুলস ইঞ্জিন ফ্রিতে আজীবন কাজ করবে।
