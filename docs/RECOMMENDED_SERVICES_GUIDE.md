# 🚀 Webmaa প্রোডাকশন ক্লাউড সার্ভিস বাস্তবায়ন গাইড (ধাপ-ধাপ নির্দেশিকা)

এই গাইডে আমাদের প্ল্যাটফর্মের জন্য সবচেয়ে উপযোগী ৫টি ফ্রি ক্লাউড সার্ভিস কীভাবে খুব সহজে এবং কোনো বাড়তি কোড ব্লোট ছাড়া ধাপে ধাপে সেটআপ করবেন, তা বাংলায় বিস্তারিত দেওয়া হলো।

## ১. Resend (অর্ডার ও ইনভয়েসের জন্য ট্রানজেকশনাল ইমেইল)
> **ফ্রি কোটা:** ৩,০০০ ইমেইল/মাস (কোনো ক্রেডিট কার্ড ছাড়াই শুরু করা যায়)।  
> **কেন দরকার:** জিমেইল বা সাধারণ SMTP মাঝে মাঝে স্প্যাম বক্সে ফেলে দেয় অথবা গুগল অ্যাকাউন্ট ব্লক করে। Resend এর ডেলিভারি রেট ৯৯.৯%।

### ধাপ ১: ফ্রি অ্যাকাউন্ট ও API Key সংগ্রহ
1. [resend.com](https://resend.com)-এ গিয়ে **Sign Up** করুন (GitHub দিয়ে লগইন করা যায়)।
2. ড্যাশবোর্ডে গিয়ে **API Keys** ট্যাবে যান এবং **Create API Key**-এ ক্লিক করুন।
3. নাম দিন `webmaa-email` এবং পারমিশন **Full Access** রেখে কি তৈরি করুন। কি-টি কপি করুন (যেমন: `re_123456789...`)।

### ধাপ ২: ডোমেইন ভেরিফিকেশন (ইনবক্স ডেলিভারির জন্য)
1. Resend ড্যাশবোর্ডে **Domains > Add Domain**-এ যান।
2. আপনার ডোমেইন নাম লিখুন (যেমন: `bdretailers.com`)।
3. Resend আপনাকে ৩টি DNS রেকর্ড দেবে (SPF, DKIM, MX)।
4. আপনার ডোমেইন প্রোভাইডার (Cloudflare/Namecheap)-এ গিয়ে এই ৩টি DNS রেকর্ড বসিয়ে **Verify DNS Records** বাটনে চাপ দিন। (ভেরিফাই হলে সবুজ টিক দেখাবে)।

### ধাপ ৩: আমাদের প্রজেক্টে যুক্ত করা (০ কোড পরিবর্তন!)
আমাদের প্রজেক্টের `src/app/api/superadmin/broadcast-email/route.js`-এ ইতিমধ্যে Nodemailer ট্রান্সপোর্টার তৈরি আছে। Resend সরাসরি SMTP সাপোর্ট করে।  
আপনার `.env.local` এবং Vercel Dashboard-এর **Settings > Environment Variables**-এ নিচের মানগুলো বসিয়ে দিন:

```env
SMTP_HOST=smtp.resend.com
SMTP_PORT=465
SMTP_USER=resend
SMTP_PASS=re_আপনার_সংগৃহীত_API_KEY
EMAIL_FROM="BD Retailers <orders@bdretailers.com>"
```
ব্যাস! এখন থেকে প্রতিটি অর্ডার কনফার্মেশন ও ইনভয়েস সরাসরি কাস্টমারের ইনবক্সে চলে যাবে।

## ২. Cloudflare (ফ্রি DNS, DDoS, SSL ও কাস্টম ডোমেইন)
> **ফ্রি কোটা:** আজীবন ১০০% ফ্রি।  
> **কেন দরকার:** সাইটের লোডিং স্পিড বহুগুণ বাড়ে, ফ্রি SSL পাওয়া যায়, হ্যাকারদের বট অ্যাটাক ও DDoS ঠেকায়, এবং আমাদের প্ল্যাটফর্মের রিটেইলারদের কাস্টম ডোমেইন (যেমন: `camerakini.com`) খুব সহজে রাউট করা যায়।

### ধাপ ১: Cloudflare-এ সাইট অ্যাড করা
1. [cloudflare.com](https://cloudflare.com)-এ ফ্রি অ্যাকাউন্ট খুলুন।
2. **Add a site** বাটনে ক্লিক করে আপনার ডোমেইন নাম লিখুন (যেমন: `bdretailers.com`)।
3. প্ল্যান হিসেবে **Free ($0)** প্ল্যানটি নির্বাচন করুন।
4. Cloudflare স্বয়ংক্রিয়ভাবে আপনার বর্তমান DNS রেকর্ডগুলো স্ক্যান করে নেবে।

### ধাপ ২: নেমসার্ভার পরিবর্তন (Nameservers Change)
1. Cloudflare আপনাকে ২টি নেমসার্ভার দেবে (যেমন: `amy.ns.cloudflare.com` এবং `dane.ns.cloudflare.com`)।
2. আপনি যেখান থেকে ডোমেইন কিনেছেন (Namecheap, GoDaddy, ইত্যাদি), সেখানে লগইন করে **Custom DNS / Nameservers** অপশনে এই ২টি নেমসার্ভার বসিয়ে সেভ করুন।
3. সাধারণত ১৫-৩০ মিনিটের মধ্যে ডোমেইন ক্লাউডফ্লেয়ারের আন্ডারে চলে আসে।

### ধাপ ৩: Vercel-এর সাথে কানেক্ট করা
Cloudflare ড্যাশবোর্ডে **DNS > Records**-এ গিয়ে নিচের ২টি রেকর্ড দিন:
1. **A Record:**
   - Name: `@`
   - IPv4 Address: `76.76.21.21` (Vercel IP)
   - Proxy status: **Proxied (Orange Cloud)**
2. **CNAME Record:**
   - Name: `www`
   - Target: `cname.vercel-dns.com`
   - Proxy status: **Proxied (Orange Cloud)**
3. **SSL/TLS সেটিং:** **SSL/TLS > Overview**-এ গিয়ে এনক্রিপশন মোড **Full (strict)** সিলেক্ট করুন (যাতে কোনো SSL এরর না আসে)।

## ৩. Upstash Redis (রেট লিমিটিং ও ওটিপি স্প্যাম প্রোটেকশন)
> **ফ্রি কোটা:** প্রতিদিন ১০,০০০ কমান্ড সম্পূর্ণ ফ্রি।  
> **কেন দরকার:** হ্যাকাররা বা রোবট যেন মোবাইল ওটিপি বা চেকআউট বাটনে ক্লিক করে এসএমএস বিল বাড়িয়ে না ফেলে এবং সার্ভার ডাউন না করতে পারে।

### ধাপ ১: ফ্রি Redis ডাটাবেজ তৈরি
1. [upstash.com](https://upstash.com)-এ গিয়ে GitHub বা Google দিয়ে ফ্রি অ্যাকাউন্ট খুলুন।
2. **Redis > Create Database**-এ ক্লিক করুন।
3. ডাটাবেজ নাম দিন `webmaa-ratelimit`, রিজিয়ন নির্বাচন করুন **ap-southeast-1 (Singapore)** (যেহেতু বাংলাদেশ থেকে সিঙ্গাপুর সবচেয়ে দ্রুত)।
4. **Primary** টাইপ রেখে **Create** চাপুন।

### ধাপ ২: REST URL ও Token কপি করা
ডাটাবেজ ড্যাশবোর্ডের নিচে স্ক্রল করলে **REST API** সেকশনে পাবেন:
- `UPSTASH_REDIS_REST_URL` (যেমন: `https://ap1-xxxx.upstash.io`)
- `UPSTASH_REDIS_REST_TOKEN` (যেমন: `AXxxASQgxxxx...`)

### ধাপ ৩: আমাদের প্রজেক্টে যুক্ত করা (অলরেডি কোড রেডি!)
আমাদের `src/lib/rate-limit.js`-এ ইতিমধ্যে Upstash কানেকশন কোড লেখা আছে!  
শুধু আপনার `.env.local` এবং Vercel Dashboard-এ নিচের ভ্যারিয়েবল দুটি বসিয়ে দিন:

```env
UPSTASH_REDIS_REST_URL=https://ap1-xxxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=AXxxASQgxxxx...
```
ব্যাস! এখন স্বয়ংক্রিয়ভাবে পুরো প্ল্যাটফর্ম বট অ্যাটাক ও ওটিপি স্প্যামিং থেকে সুরক্ষিত হয়ে যাবে।

## ৪. PostHog (প্রোডাক্ট ফানেল ও কার্ট ড্রপ অ্যানালিটিক্স)
> **ফ্রি কোটা:** প্রতি মাসে ১০ লাখ (1M) ইভেন্ট ও ৫,০০০ সেশন রেকর্ডিং ফ্রি।  
> **কেন দরকার:** কোন কাস্টমার কোন প্রোডাক্ট দেখে কার্টে যুক্ত করল কিন্তু শেষ পর্যন্ত অর্ডার করল না (Cart Abandonment), তা ভিডিও সহ এবং চার্ট আকারে দেখা যায়।

### ধাপ ১: ফ্রি অ্যাকাউন্ট ও API Key নেওয়া
1. [us.posthog.com](https://us.posthog.com)-এ গিয়ে সাইনআপ করুন।
2. রিজিয়ন হিসেবে **US Cloud** বা **EU Cloud** সিলেক্ট করুন।
3. **Project Settings**-এ গেলে আপনার **Project API Key** (যেমন: `phc_xxxx...`) এবং **API Host** (`https://us.i.posthog.com`) পাবেন।

### ধাপ ২: লাইভ ট্র্যাকিং চালু করা
আমাদের প্ল্যাটফর্মের `src/components/shared/PlatformAnalytics.jsx` স্বয়ংক্রিয়ভাবে গ্লোবাল কনফিগারেশন থেকে স্ক্রিপ্ট লোড করতে পারে।  
অথবা আপনি সরাসরি আপনার সুপারএডমিন ড্যাশবোর্ডের **Settings > Tracking / Analytics** প্যানেলে গিয়ে Google Tag Manager বা PostHog Snippet বসিয়ে দিলেই পুরো প্ল্যাটফর্মে রিয়েল-টাইম কাস্টমার ফানেল চালু হয়ে যাবে।

## ৫. Sentry (রিয়েল-টাইম ক্র্যাশ ও এরর ট্র্যাকিং)
> **ফ্রি কোটা:** প্রতি মাসে ৫,০০০ এরর ট্র্যাকিং সম্পূর্ণ ফ্রি।  
> **কেন দরকার:** মোবাইল অ্যাপের Flutter WebView-তে জাভাস্ক্রিপ্ট আটকে গেলে বা চেকআউটে কোনো গ্রাহক এরর ফেস করলে, গ্রাহক অভিযোগ করার আগেই আপনার কাছে ইমেইল চলে আসবে ঠিক কোন লাইনে কেন এরর হয়েছে।

### ধাপ ১: Sentry প্রজেক্ট তৈরি
1. [sentry.io](https://sentry.io)-এ গিয়ে ফ্রি অ্যাকাউন্ট খুলুন।
2. **Projects > Create Project**-এ গিয়ে প্ল্যাটফর্ম হিসেবে **Next.js** নির্বাচন করুন।
3. অ্যালার্ট অপশনে **Alert me on every new issue** টিক দিন এবং Create Project চাপুন।

### ধাপ ২: DSN সংগ্রহ ও প্রজেক্টে বসানো
Sentry আপনাকে একটি **DSN** দেবে (যেমন: `https://xxxx@o1234.ingest.sentry.io/5678`).  
`.env.local` এবং Vercel-এ যোগ করুন:

```env
NEXT_PUBLIC_SENTRY_DSN=https://xxxx@o1234.ingest.sentry.io/5678
```
এখন যেকোনো ক্র্যাশ বা অস্বাভাবিক বাগ তাৎক্ষণিকভাবে ট্র্যাক হয়ে যাবে।
