# Agentic Awesome Skills (sickn33/agentic-awesome-skills)

Integrated agent playbook inventory and instruction control plane for autonomous coding agents (Antigravity, Claude Code, Cursor, Codex).

## Core Capabilities & Catalog Areas

### 1. Application Security & Vulnerability Auditing
- **STRIDE & PASTA Threat Modeling**: Systematic mapping of Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, and Elevation of Privilege across Next.js API routes and Firestore security rules.
- **Dependency Guard**: Automated checking against CVEs (including Brotli/zlib denial-of-service and prototype pollution).
- **L7 Injection Hunting**: Verification of NoSQL queries, DOM XSS prevention, and sanitized server-side parameters.

### 2. Architecture & High-Performance Web
- **Zero-Bloat Verification (Ponytail Standard)**: YAGNI decision ladder integration to prevent speculative abstraction and dead dependencies.
- **Multi-Tenant State Isolation**: Safe separation of shop data, staff roles, and impersonation sessions.
- **Web Audio & 60fps Micro-Interactions**: Native Web Audio API tactile feedback and GPU-accelerated spring animations without external runtime dependencies.

### 3. REA & API-First Catalog Integration
- **Reverse Engineer Anything (REA)**: Deconstructing competitor single-page apps, network contracts, and API keys (`x-api-key`, bearer tokens) from client bundles.
- **API-Anything Direct Ingestion**: Replacing slow headless browser scraping with direct JSON REST / GraphQL calls for 100x faster throughput.

## Usage Protocol
When a complex architecture, threat model, or competitor platform integration is requested:
1. Identify the task category (Security, Reverse-Engineering, UI Polish, Multi-tenant Architecture).
2. Synthesize the relevant agentic playbook with Ponytail anti-bloat standards.
3. Validate deterministic code quality before deployment.
